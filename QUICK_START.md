# Achievement Jar - Quick Start Guide 🚀

## 30-Second Setup

1. **Start the app**
   ```bash
   npm run dev
   ```

2. **Navigate to Achievement Jar**
   - Click sidebar → **Inspiration** → **Achievement Jar**

3. **Add your first achievement**
   - Click **"Add Achievement"** button
   - Fill in title and description
   - Choose icon and color
   - Click **"Add Achievement"**

4. **Done!** Your achievement is now floating beautifully on screen.

---

## Quick Actions

| Action | How To |
|--------|--------|
| **Add Achievement** | Click "+ Add Achievement" button |
| **View Details** | Click any achievement card |
| **Edit Achievement** | Click achievement → "Edit" button |
| **Delete Achievement** | Click achievement → "Delete" button |
| **Switch View** | Click "Floating View" or "Grid View" |
| **Filter by Time** | Use dropdown: All Time / Week / Month / Year |

## What to Add First

### Start with 3 Recent Wins
1. Something from this week
2. Something from this month
3. Something you're really proud of

### Example First Achievements
- "Completed this habit dashboard setup"
- "Committed to personal growth journey"
- "Started tracking my achievements"

## Pro Tips

1. **Add immediately** - Don't wait, capture the moment
2. **Be specific** - Details make it powerful
3. **Include feelings** - "I felt unstoppable"
4. **Mix big & small** - All victories count
5. **Review regularly** - Make it a habit
