   - Click "This Month" → heatmap shows last 30 days
   - Click "This Week" → heatmap shows last 7 days
   - Click "This Year" → heatmap shows last 365 days

   Solution: Created dynamic monthLabels calculation

   - Labels generated from actual heatmap data
   - Only shows months with data
   - Updates when time range changes
   - Works for any date range

================================================================================
                          TECHNICAL CHANGES
================================================================================

File Modified: src/pages/Analytics.jsx

Change 1: Heatmap Generation
  Before: useMemo(() => { ... }, [historyData])
  After:  useMemo(() => { ... }, [historyData, timeRange])
  
  Added logic to respect timeRange:
  - if timeRange === 'week': startDate = 7 days ago
  - if timeRange === 'month': startDate = 30 days ago
  - if timeRange === 'year': startDate = 365 days ago
  - if timeRange === 'all': startDate = earliest date in history

Change 2: Month Labels
  Added new useMemo for monthLabels:
  - Generates labels from heatmap data
  - Only includes months with data
  - Updates when heatmap changes

Change 3: Heatmap Rendering
  - Now uses dynamic monthLabels instead of hardcoded months
  - Title shows selected time range
  - Everything updates when buttons are clicked

================================================================================
                            HOW IT WORKS NOW
================================================================================

User Flow:
1. User clicks "This Month" button
2. setTimeRange('month') is called
3. Heatmap useMemo recalculates with 30-day filter
4. Month labels useMemo generates labels for those 30 days
5. UI updates with new data and labels
6. Metrics update for the 30-day range

Data Flow:
  Button Click
      ↓
  setTimeRange(range)
      ↓
  heatmapData useMemo updates
      ↓
  monthLabels useMemo updates
      ↓
  UI re-renders

================================================================================
                          WHAT EACH BUTTON DOES
================================================================================

This Week (7 days):
  - Shows last 7 days of data
  - Heatmap displays 1 week
  - Month labels show relevant months
  - Metrics calculated for 7 days

This Month (30 days):
  - Shows last 30 days of data
  - Heatmap displays ~4 weeks
  - Month labels show current month (and previous if needed)
  - Metrics calculated for 30 days

This Year (365 days):
  - Shows last 365 days of data
  - Heatmap displays full year
  - Month labels show all 12 months
  - Metrics calculated for 365 days

All Time:
  - Shows from first logged date to today
  - Heatmap displays entire history
  - Month labels show all months with data
  - Metrics calculated for entire history
